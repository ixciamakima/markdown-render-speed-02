# Ixcia Markdown

A dependency-free Markdown renderer (block + inline parser in `parse.js`, driver in `main.ts`) that reproduces `marked` 18.1.3's HTML output byte-for-byte — 720/720 on the competition corpus — at roughly 0.7x marked's CPU time.
